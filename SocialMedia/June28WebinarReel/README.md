# June 28 Webinar Reel

Remotion project for FEDSafe social and website video assets.

## Prerequisites

- Node.js 20+
- npm install completed in this folder

## Commands

```bash
npm run preview
npm run still
npm run render
```

## Output

- Still frame: `out/preview.png`
- Video render: `out/fedsafe-june28-webinar-reel.mp4`

Copy finalized media assets into the website project only after review approval.
